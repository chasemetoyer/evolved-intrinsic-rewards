# Release materials

This release accompanies "Satisfied, Not Solving: Wireheading of Bounded Homeostatic Rewards in Reinforcement
Learning". It holds:
- the pre-registrations and their hash records;
- the run records and the scored result files;
- the checkpoints;
- the training code as used in the paper;
- the paper's data and scripts.

`SHA256SUMS` lists every file in this folder.

Section numbers refer to the paper: §3 Setup, §4 Theory, §5.1-§5.5 results C1-C5, §6 "What our pre-registered
predictions got wrong", §7 Discussion, §8 Limitations, and Appendices A-G.

## Notes

- **Code versions.** `code/` is the version used in round 5. Earlier rounds ran earlier versions, from before
  options such as the tamper action and the press cost were added. The round-4 and round-5 pre-registrations each
  record a regression check: with the new options off, training was bit-identical to the previous round's code.
  The exact code of every run is identified by the commit in `run-records/run-list.txt`. That code is not included
  here.
- **To reproduce a run:** use `uv sync --locked` in `code/`, copy a run's `config.toml` into place, and run
  `./run.sh`.
- **KeyCorridor names.** The paper names the KeyCorridor runs K1-K6. The files here call them C1-C6, and Table 11
  maps the names.
- **Paths.** In run commands and logs, the home directory is replaced by `~`.
- **Excluded from this release.**
  - One run directory found in the local run store (`9019b614`) belongs to an unrelated project and is excluded.
  - The repository copies inside each run directory, including their Python environments, are excluded.
